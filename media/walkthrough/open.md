# Open a MyST document

MyST Notebook opens your `.md` source directly in VS Code's notebook editor —
the source file **is** the notebook.

1. Open a `.md` file that is part of a MyST / Jupyter Book project (one with a `myst.yml`).
2. Click **Open as MyST Notebook** in the editor toolbar, or run **MyST: Open as MyST Notebook** from the Command Palette.

To make it the default for `.md`, run **Configure default editor for '.md'** and pick **MyST Notebook**.
