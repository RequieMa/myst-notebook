# Run a code cell

- **Ctrl+Shift+E** — insert an executable `{code-cell}` (collapsed, cursor inside).
- **Shift+Enter** — run the cell; output streams in live.
- **Ctrl+D** — delete the selected cell (when not editing).

MyST launches its own Jupyter server in the Python environment you choose — the
full Jupyter extension is not required. If `ipykernel` / `jupyter-server` are
missing, MyST offers to install them.
